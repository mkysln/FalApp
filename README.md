# Nazar (FalApp)

Nazar, fal türü seçip bir soru üzerinden yorum alma fikri etrafında tasarlanan bir mobil uygulama prototipidir. Projenin amacı, bu deneyimi görsel açıdan özenli ve akıcı bir React Native arayüzünde sunmaktır.

Uygulama tarafında fal türleri ve soru akışı için ekranlar bulunur. Yapay zekâ ile yorum üretimi eklenecekse sağlayıcı bağlantısının güvenli bir backend üzerinden yapılması planlanmalıdır; gizli API anahtarları mobil uygulamanın içine konmamalıdır.
